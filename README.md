SAFARNAAMA is a visually captivating tourism website designed to ignite your wanderlust and simplify your travel planning experience. This demo project showcases the front-end of a tourism agency platform, built using HTML, CSS, and JavaScript.

✈️ Key Features:
Aesthetic and responsive design

Easy navigation for a seamless user experience

Informative sections to guide and inspire travelers

🚀 How to Run:
Download the repository

Open the index.html file in your preferred browser
